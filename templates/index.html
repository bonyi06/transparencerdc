Espace administrateur

Saisissez vos identifiants nominatifs pour modifier les contenus publics.

Gérer les comptes administrateur

Chaque personne doit avoir son propre compte nominatif (traçabilité des modifications). Réservé au rôle « admin ».

Journal d'activité

Historique des connexions et modifications (200 dernières entrées).

Gérer les rapports

Ajoutez, modifiez ou supprimez les rapports affichés au public.

Gérer les rubriques

Choisissez les rubriques visibles dans le menu, pour vous et pour les visiteurs du site. « Vue d'ensemble » reste toujours accessible (page d'accueil).

Enrichir les données

Ajoutez les données d'une nouvelle année (ou corrigez une table) en important un fichier CSV ou JSON. Téléchargez d'abord le modèle de la table pour respecter exactement les colonnes attendues.
